# mako rgb

подсветка dexp mako на linux без фирменного приложения. отдельные клавиши ряды и уведомления цветом

python 3 без зависимостей. usb `2e3c:c365` интерфейс `02` раскладка на 68 клавиш

## запуск

```sh
python3 mako.py list
python3 mako.py key w 255 0 0 10
python3 mako.py row 1 0 0 255 5
python3 mako.py all 255 0 255 8
python3 mako.py rows 10
python3 mako.py off 5
python3 mako.py blink 255 0 255 5
python3 mako.py notify purple 2
```

rgb от 0 до 255. время в секундах и число циклов положительные целые. по умолчанию 10 секунд для цвета 5 циклов для blink и 2 для notify

## доступ к клавиатуре

нужны права на запись в соответствующий hidraw. утилита сама находит интерфейс через sysfs. не выдавай всем пользователям доступ ко всем hidraw и не запускай неизвестные скрипты от root

## как работает

64 байта на пакет. команда `0x17` включает поклавишный режим затем `0x0f` отправляет кадр из десяти пакетов

цвет временный. для удержания кадры переотправляются. после остановки ожидается возврат режима клавиатуры но это зависит от прошивки. off тоже временный

команды глобального режима `0x07` и записи во flash `0x21` в публичную версию не включены

устройство открывается без создания или усечения файла. символьные ссылки и обычные файлы вместо устройства отвергаются до записи
